# 🧠 Key Learning Approach

The main goal of this workshop is not simply to learn how to create charts.

The learning process is:

> **Data → Analysis → Visualization → Insight → Decision**

For each visualization, the focus is on understanding:

- What data is being represented?
- Why is this visualization appropriate?
- What pattern or trend does it show?
- What insight can be extracted?
- How can the insight support decision-making?
